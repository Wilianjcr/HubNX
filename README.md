# HubNX

Projeto privado de testes para Nintendo Switch 1 e Android.

## Estrutura planejada

- `android/`: interface PWA para gerenciar sites favoritos.
- `switch/`: código do aplicativo homebrew independente.
- `firebase/`: regras de sincronização por usuário.
- `version.json`: metadados de versões.

**Estado:** projeto em testes. O homebrew `.nro` ainda não foi compilado nem testado no console. Netflix pode abrir como site, mas a reprodução é limitada por DRM.

O repositório deve permanecer privado durante a validação.
