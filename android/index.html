Ativar Conta HubNX

Para criar contas e sincronizar favoritos, configure um projeto no Firebase Console. Ative Authentication (E-mail/Senha), Firestore e as regras de acesso por usuário descritas no GitHub.

Esses dois identificadores são configurações públicas de aplicativo web, não senhas de administrador. A configuração ficará salva só neste dispositivo.
